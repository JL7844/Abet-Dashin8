# ABET DASHEN

### *Real-Time Zero-Trust Attendance Management System*

---

## 📌 Overview

ABET DASHEN is a real-time attendance management system designed for secure and high-trust environments such as Dashen Bank. It uses face recognition combined with 3-point biometric verification to ensure accurate and fraud-resistant attendance tracking.

The system provides a live monitoring dashboard, instant verification updates, and continuous tracking of staff presence in a modern, interactive interface.

---

## ❗️ Problem Statement

Traditional attendance systems have critical limitations:

* Manual attendance tracking is time-consuming and error-prone
* Proxy attendance and fraud are difficult to detect
* Lack of real-time monitoring for staff presence
* No intelligent verification system for secure environments
* Existing solutions are not suitable for high-security institutions like Dashen Bank

---

## ⚙️ How It Works

ABET DASHEN follows a Zero-Trust verification model, meaning every attendance action must be verified in real time.

* Users are verified using face recognition + 3-point biometric checks
* Each check-in is instantly processed and displayed on the dashboard
* Attendance status is continuously updated:

  * 🟢 Verified
  * 🟡 Pending
  * 🔴 Suspicious
* A live activity feed shows system actions in real time
* The system simulates real-time updates for transparency and monitoring
